# Graham Quan Blog

## Tech Stack

- Next.js v15 App Router
- Tailwind CSS v4 (Mobile Responsive and Dark/Light Mode)
- TypeScript
- React
- mdx or Markdown
- ESLint
- Prettier
- Shiki (Code Snippet Highlighting)
- Google Analytics 4 (GA4)
- Vercel
- Cloudflare Pages
- Dymamic Sitemap

## Environment Variables

### Vercel

```sh
cp .env.example .env.local
```

## Getting Started with pnpm

### install

```sh
pnpm install
```

### development mode

```sh
pnpm dev
```
